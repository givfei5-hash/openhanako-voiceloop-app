## Voiceloop 2.2.2 — 群聊与巡检，都不再被念出来

给 Hana 的 agent 一张嘴：**开场**轻问候、**过程**按档位报进展、**收尾**念结论；三段由应用通过钩子主动介入，句子由会话模型**现写**。

v2 应用（Hana ≥ `1.0.4-beta`）。安装包：`app-voiceloop-2.2.2.zip`。

### 2.2.2 修了什么

**助理群聊 / 转发的消息被念出来**（真机发现）：几个助理在一个频道里群聊（会话在 `agents/<助理>/phone/sessions/ch_xxx/`），应用把那些回合也念了。这类回合的提示词其实写得很清楚：

> 你的手机收到了 #ch_xxx 的**新群聊消息**……**不是用户单独发给你的请求**

现在把「群聊频道会话」与「非用户本人的转发消息」都当**非用户回合**：

- 会话路径含 `phone/sessions/ch_`（频道会话）→ 静默
- 提示词含 `新群聊消息` / `不是用户单独发给你的请求` / `频道聊天记录` / `非用户本人` / `[来自 Agent…]` → 静默

命中即**开场 / 过程 / 收尾全静默**；用户自己的会话不受影响。

### 真机验证（2026-10-09）

| 场景 | 证据 |
| --- | --- |
| 群聊回合 | 测试帖发出后 5 个频道回合（19:44:05 / 19:44:22 / 19:44:25 / 19:44:46 / 19:45:31）**零播报**；同期只念了 1 条，属于用户自己的桌面会话 |
| 巡检回合 | 手动触发心跳（19:50:53 → 19:52:15，1m22s），窗口内**巡检回合零播报**；修复前那次心跳结束后 8 秒必念「巡检完毕…」，这次没有 |
| 内部块 | 上述群聊回合的回复正文里带 `<mood>` / `<reflect>` 块，同样没有被念出来 |
| 用户回合 | 对照组：用户自己的会话照常出声（开场 / 过程 / 收尾齐全） |

### 这一版有什么

- 三段播报：开场 / 过程 / 收尾，应用主动、模型现写，不是模板句
- 播报密度四档：紧凑（每工具步）/ 标准（每 2 步，默认）/ 稀疏（每 4 步）/ 安静（过程不播）
- 播报风格四档（同时决定收尾长度）：俏皮 ≈140 字 / 平实 ≈80 / 温柔 ≈220 / 干练 ≈100
- 合成策略四档：云端 Edge / 云端优先+来源兜底 / 只用来源 / 媒体引擎专属
- 来源二选一：HanaAgent 内置媒体引擎（豆包 TTS，零配置）或自配置 OpenAI 兼容 TTS API
- 六个云端音色的 24 kHz 参考音随包预合成；本地 TTS 部署是可选增强
- **静默纪律**：巡检 / 心跳 / 定时任务 / 群聊频道 / 转发消息一律不播；内部块（`<pulse>`/`<mood>`/`<think>`… 及任何成对标签块）不外泄；剥完为空则一个字都不念
- 12 项声明能力，逐条可审可撤
