## Voiceloop 2.2.3 — 换个口气介绍自己（代码与 2.2.2 一致）

**让 Hana 开口说话。** 对话框里它只会写字：你盯着屏幕等结果，它闷头干活、一句不吐。装上 Voiceloop，它变成会说话的那一个——新会话先打个招呼、干活中间报一声进展、收尾把结论念给你听。配上语音输入，它就是**你自己的贾维斯**。

### 这一版改了什么

只改文案，**应用代码与 2.2.2 完全一致**（2.2.2 是已通过真机验证的那份）：

- **商店描述**：从功能口径（“给 Hana 一个声音…”）换成「让 Hana 开口说话…」的叙述口径，并保留四档策略/风格/密度与静默纪律的说明
- **仓库 README**（中/英）：开头重写为“让小花开口说话”（小花 = 你的 Hana 助手，名字随你起），并把「闭环输入」那节补了一句区分：*语音助手是你问一句它答一句；这个是“在你不看屏幕的时候，依然把进展说清楚”*
- 仓库简介与 topics 同步（新增 `human-computer-interaction`）

因为市场登记还没合并，为了让上架的那一份就带着新描述，才单独出了这个版本；功能与 2.2.2 一致，验证结论沿用（见下）。

### 功能一览（与 2.2.2 相同）

- 三段播报：开场 / 过程 / 收尾，应用主动、模型现写，不是模板句
- 播报密度四档：紧凑（每工具步）/ 标准（每 2 步，默认）/ 稀疏（每 4 步）/ 安静（过程不播）
- 播报风格四档（同时决定收尾长度）：俏皮 ≈140 字 / 平实 ≈80 / 温柔 ≈220 / 干练 ≈100
- 合成策略四档：云端 Edge / 云端优先+来源兜底 / 只用来源 / 媒体引擎专属
- 来源二选一：HanaAgent 内置媒体引擎（豆包 TTS，零配置）或自配置 OpenAI 兼容 TTS API
- 六个云端音色的 24 kHz 参考音随包预合成；本地 TTS 部署是可选增强
- **静默纪律**：巡检 / 心跳 / 定时任务 / 群聊频道 / 转发消息一律不播；内部块（`<pulse>`/`<mood>`/`<think>`… 及任何成对标签块）不外泄；剥完为空则一个字都不念
- 12 项声明能力，逐条可审可撤

### 已验证（沿用 2.2.2 的真机结论）

- 离线套件：上线验收 17/17、设置项生效核查 17/17、静默/独白 13/13、长任务四档全过
