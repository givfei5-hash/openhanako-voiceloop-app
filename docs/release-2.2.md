## Voiceloop 2.2 — 内部块不再被念出来

给 Hana 的 agent 一张嘴：**开场**轻问候、**过程**按档位报进展、**收尾**念结论；三段全部由应用通过钩子主动介入，句子由会话模型**现写**。

这是 **v2 应用**（Hana ≥ `1.0.4-beta`，清单里声明的 `minAppVersion`），不是原来的技能版（[openhanako-voiceloop-skill](https://github.com/givfei5-hash/openhanako-voiceloop-skill)）。它把 Hana 1.0 引入的 v2 应用体系用到底：钩子拿节奏、设置页拿控制权、媒体总线拿声音、权限账本拿信任。

**装法**：把 `app-voiceloop-2.2.zip` 装进 Hana（应用管理 → 安装），或在应用市场里找 Voiceloop。

### 2.2 修了什么

**内部块泄漏（真机抓到的现行）**：助手在回复里写 `<mood>…</mood>` 这类**心声块**时，应用会把标签和心声一起念出来——日志里抓到过 `text=<mood>` 这种字面的播报。原因是剥离逻辑只认 `<pulse>/<reflect>/<think>` 三种；另外收尾的模型压缩失败时，兜底会去念**原文开头**，剥不干净就会把内部内容带出来。

现在改成三层：

1. **已知名单**（`pulse / mood / reflect / think / inner / feeling / emotion / state / analysis / reasoning / meta / plan / note / aside …`）成对块与落单标签都剥
2. **兜底**：任何“成对标签块”一律当内部块剥掉——以后再有没见过的块名也不会漏
3. **模型输出**（开场/过程/收尾的写法本身）也过同一条清洗，万一模型吐标签也不出声

外加一条硬规矩：**剥完如果什么都不剩，就一个字都不念**（闭嘴 ≠ 念错），收尾的兜底也改成只截取剥完的正文。

### 这一版有什么

- 三段播报：开场 / 过程 / 收尾，应用主动、模型现写，不是模板句
- 播报密度四档：紧凑（每工具步）/ 标准（每 2 步，默认）/ 稀疏（每 4 步）/ 安静（过程不播）
- 播报风格四档（同时决定收尾长度）：俏皮 ≈140 字 / 平实 ≈80 / 温柔 ≈220 / 干练 ≈100
- 合成策略四档：云端 Edge / 云端优先+来源兜底 / 只用来源 / 媒体引擎专属
- 来源二选一：HanaAgent 内置媒体引擎（**豆包 TTS，零配置**）或自配置 OpenAI 兼容 TTS API
- 六个云端音色的 **24 kHz 参考音随包预合成**（本地克隆开箱可用）
- 巡检 / 心跳回合全程静默、内心独白不外泄、敏感内容不播
- 12 项声明能力，逐条可审可撤

### 已验证

- 离线自测（CI 每次 push 跑）：上线验收 17/17、设置项生效核查 17/17、静默/独白 **8/8**（含新增的 `<mood>` 与未知块兜底三条）、长任务四档全过
- 真机实测（豆包链路）：开场 4.9s / 16 字，过程 3.4s / 14 字，收尾 19.6s / 99 字
